# 房间邀请链接

DHOL 前端接受 `?room=ABC123`，例如 `https://screenol.pages.dev/?room=ABC123`。
`room` 为六位英文字母或数字，读取时去除首尾空格并转换为大写；无效值忽略。

- 浏览器保存的会话属于该房间时，直接恢复会话。
- 没有对应会话时，在加入页预填邀请码；玩家填写称呼后点击「加入房间」。打开链接本身不会创建成员。
- 如果浏览器保存了另一房间的会话，优先显示链接目标的加入页。实际加入成功前保留原会话；直接打开不带参数的首页仍可恢复原房间。
- 创建、加入或恢复备份成功后，地址栏更新为实际房间的 `room` 参数，刷新不会误回原链接的目标。

房间工具栏的「分享链接」会复制当前房间的邀请链接并显示反馈。剪贴板不可用或被拒绝时，可在弹出的只读输入框中选择并手动复制。分享地址保留当前前端的 origin 和路径，只携带 `room` 参数，不含会话 token、成员 ID、其它查询参数或 hash。

外部车卡器（如 PbDH）可在已填完整房间码时提供上述链接，并用新标签页打开。房间码是加入邀请，请只分享给希望邀请的玩家。此链接不会绕过房间有效期、人数限制和既有加入接口校验。
