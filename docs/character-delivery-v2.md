# 车卡器发送到桌面契约（v2）

`POST /api/v2/rooms/:code/characters` 接收 `schemaVersion: 2` 和完整的 `sheet`。同名角色再次发送时，桌面用本次 `sheet` 覆盖上次原始数据和资源状态，并广播新的角色代次。

`sheet` 保留车卡器导出时的全部字段；桌面不能只拣选一组已知字段保存。`sheet.desktopView` 是发送按钮被点击时，车卡器界面已经计算并显示的值：闪避、护甲值、轻伤/重伤阈值、六项属性、生命/压力/护甲最大值，以及主副武器的属性和攻击距离。桌面摘要和完整信息优先显示这份快照，不重新从基础值推导。例如用户手动把轻伤阈值改为 17，即使原始字段仍保存基础值 9，桌面也显示 17。

生命与压力的原始数组可能各有 18 个存储格；桌面只展示 `desktopView.hpMax` 和 `desktopView.stressMax` 指定的实际最大值。旧版 `schemaVersion: 1` 继续支持，按旧规则读取；它不能携带 `desktopView`。
